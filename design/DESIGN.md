# DESIGN.md — 모두의회의실 디자인 시스템 (샘플 v1.0)

이 문서는 디자이너 에이전트가 화면을 생성할 때 따르는 **유일한 디자인 명세**다. 여기 없는 것은 임의로 정하지 말고 가장 보수적인 선택을 하되, 화면 상단 주석에 `<!-- 명세 없음: ... 로 판단 -->`을 남긴다.

## 1. 컬러 토큰

| 토큰 | 값 | 용도 |
|---|---|---|
| `--primary` | #2E5BFF | 주요 버튼, 활성 상태, 링크 |
| `--primary-dark` | #1E3FCC | 버튼 pressed |
| `--text-strong` | #191F28 | 제목, 본문 강조 |
| `--text-body` | #333D4B | 본문 |
| `--text-weak` | #6B7684 | 보조 설명, 라벨 |
| `--divider` | #E5E8EB | 구분선, 카드 테두리 |
| `--bg` | #FFFFFF | 기본 배경 |
| `--bg-weak` | #F4F6F8 | 페이지 배경, 비활성 칩 |
| `--success` | #12A150 | 사용 가능, 완료 |
| `--danger` | #E5484D | 오류, 사용 중, 삭제 |
| `--warning` | #B45309 | 주의 (임박, 제한) |

규칙: 텍스트는 위 토큰 외 색 사용 금지. `--text-weak`보다 연한 텍스트 색 금지 (대비 4.5:1 미만이 되기 때문).

## 2. 타이포그래피

시스템 폰트 스택: `-apple-system, BlinkMacSystemFont, "Pretendard", "Malgun Gothic", sans-serif`

| 스타일 | 크기/행간 | 굵기 | 용도 |
|---|---|---|---|
| Title | 22/30px | 700 | 화면 제목 |
| Heading | 18/26px | 700 | 섹션 제목, 카드 제목 |
| Body | 16/24px | 400 | 본문, 입력값 |
| Label | 14/20px | 500 | 필터 칩, 폼 라벨, 버튼 보조 |
| Caption | 13/18px | 400 | 보조 정보, 타임스탬프 |

규칙: **13px 미만 텍스트 금지.** 한 화면에 굵기 3종 초과 금지.

## 3. 간격·레이아웃

- 4px 그리드: 모든 여백은 4의 배수 (기본 단위 8 / 12 / 16 / 24 / 32)
- 화면 좌우 패딩 20px, 카드 내부 패딩 16px
- 카드: radius 12px, 테두리 1px `--divider`, 그림자 없음
- 기준 뷰포트 390×844, 콘텐츠 최대폭 480px 중앙 정렬

## 4. 컴포넌트

### 버튼
- Primary: 높이 52px, radius 12px, `--primary` 배경 + 흰 글자 16px/700, 화면당 1개
- Secondary: 높이 52px, `--bg-weak` 배경 + `--text-strong`
- 비활성: `--bg-weak` 배경 + `--text-weak`, `disabled` 속성 명시
- 텍스트 버튼: `--primary` 글자, 최소 터치 영역 44×44px 확보

### 필터 칩
높이 36px, radius 18px. 기본 `--bg-weak`/`--text-body`, 선택 시 `--primary` 배경 + 흰 글자. 선택 상태는 색만이 아니라 체크 아이콘(✓)으로도 구분한다.

### 시간 슬롯
30분 단위 그리드. 상태 3종 — 가능(테두리 `--divider`), 선택(배경 `--primary` + ✓), 불가(배경 `--bg-weak` + 취소선, `aria-disabled`).

### 입력 필드
높이 52px, radius 12px, 테두리 1px `--divider`, 포커스 시 `--primary` 2px. 라벨은 필드 위 Label 스타일. 플레이스홀더를 라벨 대용으로 쓰지 않는다.

### 상태 배지
사용 가능 `--success` / 사용 중 `--danger` / 곧 시작 `--warning`. 색 + 텍스트를 항상 함께 쓴다 (색만으로 의미 전달 금지).

## 5. 상태 규칙 (모든 목록·데이터 화면 필수)

1. **빈 상태**: 일러스트 없이 텍스트 2줄(무슨 상황인지 + 다음 행동) + 행동 버튼 1개
2. **로딩**: 스켈레톤(카드 모양 회색 블록). 스피너 단독 사용 금지
3. **오류**: 무엇이 실패했는지 + 재시도 버튼. "오류가 발생했습니다" 단독 금지
4. **권한 없음**: 왜 안 되는지 + 대안 안내 (예: 세미나실은 팀장 이상 예약 가능)

## 6. 접근성 (통과 기준)

- 텍스트 대비 4.5:1 이상 (큰 텍스트 18px+/700은 3:1)
- 터치 타깃 최소 44×44px, 타깃 사이 간격 8px 이상
- 모든 인터랙티브 요소는 `<button>`/`<a>` 등 시맨틱 태그 사용 (div 클릭 금지)
- 이미지·아이콘에 대체 텍스트, 상태 변화는 색+텍스트 병행
- 문서에 `lang="ko"`, 제목 계층(h1→h2→h3) 준수

## 7. 문구 톤

- 존댓말, 명사형 종결 지양: "예약이 완료됐어요" (O) / "예약 완료" 버튼 라벨은 예외
- 오류 문구는 사과보다 해결책: "잠시 후 다시 시도해 주세요" + 재시도 버튼
- 시간 표기: `오후 2:30`, 날짜 표기: `10월 30일 (금)`
