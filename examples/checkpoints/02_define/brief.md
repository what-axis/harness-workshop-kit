# 화면 브리프

## 문제 정의
- 누가: 이동 중에 한 손으로 쇼핑하며 "일단 담아 두는" 모바일 사용자
- 언제: 상품 상세에서 옵션을 고르고 장바구니에 담는 순간
- 무엇 때문에 막히는가: 담겼는지 알 수 없고, 살 수 없는 옵션은 누른 뒤에야 알며, 결국 얼마를 내는지 스스로 계산해야 한다
- 해결하지 않으면: 중복 담기와 오해로 장바구니를 정리하다 떠나고, 품절을 뒤늦게 알아 구매를 포기한다

## 목표 (이 플로우가 끝났을 때 사용자의 상태)
무엇을 얼마에 담았는지 확신하고, 보던 흐름을 이어 가거나 장바구니에서 금액을 확인할 수 있다.

## 핵심 플로우
1. 상품 상세에서 "장바구니 담기"를 누른다
2. 한 장의 시트에서 색상, 용량, 수량을 고른다 (살 수 없는 옵션은 미리 보인다)
3. 담긴 결과를 확인하고, 계속 보거나 장바구니로 간다
4. 장바구니에서 상품, 수량, 최종 금액을 확인한다

## 만들 화면 (정상 상태 기준)
| 번호 | 화면 | 이 화면에서 반드시 보여야 하는 것 |
|---|---|---|
| 01 | 상품 상세 | 상품명, 가격, 도착 예정, 색상 견본, 금액이 적힌 담기 버튼 |
| 02 | 옵션 선택 시트 | 색상(견본), 용량(품절 표시), 수량, 금액이 적힌 담기 버튼 |
| 03 | 담김 피드백 | 담긴 옵션 요약, 실행 취소, 장바구니 보기 |
| 04 | 장바구니 | 담은 상품, 수량 조절, 무료배송까지 남은 금액, 배송비 포함 최종 금액 |

## 가설과 검증 항목
| 가설 | 근거 인사이트 | 화면에서 확인할 것 (검증 항목) |
|---|---|---|
| 담은 직후 결과와 되돌리기를 보여 주면 중복 담기가 줄어든다 | 1, 7 | 담기 후 화면에 담긴 옵션 요약, 실행 취소, 다음 행동(장바구니 보기)이 모두 보인다. 장바구니로 강제 이동하지 않는다 |
| 살 수 없는 옵션을 고르기 전에 보여 주고 대안을 주면 포기가 줄어든다 | 2, 3 | 품절 옵션이 시트에서 구분되어 보이고 재입고 알림이 있다. 색상은 이름이 아니라 견본으로 고른다 |
| 최종 금액과 무료배송까지 남은 금액을 보여 주면 장바구니에서 망설임이 줄어든다 | 4 | 장바구니에 배송비 포함 금액이 한 숫자로 있고, 무료배송까지 남은 금액이 보인다 |
