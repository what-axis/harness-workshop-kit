# "나를 인터뷰해" 프롬프트

Discover 실습에서 사용합니다. 아래 프롬프트를 Claude Code 대화창에 그대로 붙여넣으세요. 목적은 두 가지입니다 — ① 문제를 내 언어로 선명하게, ② **내가 화면에서 못 참는 것**(=오후 루브릭의 '내 판단 기준')을 캐내기.

---

```
너는 시니어 UX 리서처야. 지금부터 나를 인터뷰해 줘.

주제: 나는 오늘 '모두의회의실'(사내 회의실 예약 서비스)의 화면을 디자인한다.
brief/실습용_기획서.md 와 research/ 폴더의 인터뷰 3건을 먼저 읽고 시작해.

인터뷰 규칙:
- 질문은 반드시 한 번에 하나씩. 내 답을 듣고 다음 질문을 정해.
- 총 8~10개 질문. 전반부는 문제에 대한 내 관점을, 후반부는 "내가 화면을 볼 때
  못 참는 것"을 캐내는 데 써. (예: 최근에 어떤 화면을 보고 별로라고 느꼈는지,
  그때 정확히 무엇이 거슬렸는지, 후배 시안을 반려한다면 무엇 때문일지)
- 내가 추상적으로 답하면 구체적 사례를 다시 물어. ("일관성이 없어서요" → "가장
  최근에 일관성이 깨졌다고 느낀 화면은 뭐였어요?")

인터뷰가 끝나면 outputs/판단기준_초안.md 에 저장해:
1. 내 관점 요약 (이 문제에서 내가 중요하게 보는 것 3가지)
2. 내 판단 기준 초안 — "나는 ___한 화면을 통과시키지 않는다" 형식 5개.
   각 기준마다 (a) 채점 가능하게 다듬은 문장 (b) 위반 예시 1개를 함께.
```

---

**팁**: 판단 기준은 채점할 수 있어야 오후에 루브릭이 됩니다. "세련되지 않으면 안 된다"(채점 불가) → "한 화면에 강조색이 2개를 넘으면 안 된다"(채점 가능). 인터뷰 후 초안을 보고, 채점 불가능한 문장이 있으면 Claude에게 "이 기준을 채점 가능하게 바꿔줘"라고 요청하세요.
