# 기획서 · Studio Mono 장바구니 담기 개선

> 실습용 가상 서비스입니다. 실제 회사와 관련이 없습니다.

## 배경

Studio Mono는 텀블러, 파우치 같은 생활용품을 파는 모바일 웹 커머스입니다. 방문자의 대부분이 모바일이고, 상품 상세까지는 잘 들어오지만 장바구니에 담는 단계에서 이탈이 많습니다.

- 상품 상세 조회 대비 장바구니 담기 비율이 낮음
- 고객센터 문의 상위: "담았는데 장바구니에 없어요", "담고 보니 품절이래요", "무료배송 기준이 얼마예요"
- 같은 상품을 두 번 담는 중복 담기가 잦음

## 이번에 할 일

**상품 상세에서 옵션을 고르고 장바구니에 담아, 장바구니에서 확인하기까지**의 모바일 플로우를 다시 설계합니다.

## 대상 상품 (화면에 쓸 데이터)

| 항목 | 값 |
|---|---|
| 브랜드 | STUDIO MONO |
| 상품명 | 데일리 텀블러 500ml |
| 가격 | 38,000원 (정가 42,000원) |
| 색상 | 세이지, 샌드, 차콜 |
| 용량 | 350ml, 500ml, 750ml (750ml 는 품절) |
| 후기 | 평점 4.8, 1,204건, 재구매 31% |
| 배송 | 18시 전 주문 시 내일 도착, 5만 원 이상 무료배송, 미만은 3,000원 |
| 함께 보는 상품 | 실리콘 스트랩 9,000원, 리드 교체 세트 12,000원, 코튼 파우치 16,000원 |

## 요구 사항

1. 옵션(색상, 용량, 수량)을 고르고 담을 수 있다.
2. 담은 뒤 사용자가 다음에 할 일을 고를 수 있다(계속 보기, 장바구니 가기).
3. 장바구니에서 담은 상품과 결제 예상 금액을 확인할 수 있다.

## 범위 밖

- 로그인, 결제, 주문 완료
- PC 화면
- 상품 목록, 검색

## 제약

- 화면 크기 390 x 844 (모바일 웹)
- 디자인 규칙은 `DESIGN.md` 를 따른다
