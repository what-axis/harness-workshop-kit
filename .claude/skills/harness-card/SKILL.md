# 내 업무 하네스 카드

오늘 실습한 구조를 사용자의 실제 업무 하나에 옮깁니다. 질문을 하나씩 하며 `templates/harness-card.md` 양식을 채워 `04_deliver/my-harness-card.md` 로 저장합니다.

## 질문 순서 (한 번에 하나)

1. 다음 주에 실제로 해야 하는 화면 작업 중, AI에게 시켜 보고 싶은 것 하나는?
2. 그 작업에서 AI가 꼭 읽어야 하는 자료는 무엇인가요? (디자인 시스템, 기존 화면, 정책 문서)
3. 그 결과물을 리뷰할 때 반드시 보는 것 세 가지는? (오늘 만든 `01_discover/my-criteria.md` 를 보여 주며 고르게 해도 됨)
4. 그중 숫자로 잴 수 있는 것과 사람이 봐야 하는 것은 각각 무엇인가요?
5. 몇 번까지 고치게 하고, 언제 사람이 개입할까요?
6. 회사에서 이걸 하려면 걸리는 것은? (계정, 보안, 승인)

## 마무리

- 카드를 보여 주고 고칠 곳을 묻습니다.
- 마지막에 "월요일에 할 첫 행동 한 가지"를 한 줄로 받아 카드 맨 아래에 적습니다.
- 오늘 만든 파일 중 회사로 가져갈 것을 목록으로 알려 줍니다: `.claude/agents/`, `.claude/skills/`, `04_deliver/rubric.md`, `04_deliver/qa-checklist.md`, `scripts/`.
