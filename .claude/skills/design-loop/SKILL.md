# 디렉터 루프 스킬

screens/의 현재 화면을 하네스에 태워 통과할 때까지 반복한다. **최대 3회 반복** 후에는 무조건 멈추고 사람에게 보고한다.

## 한 사이클의 순서

1. **채점**: reviewer 에이전트에게 "screens/의 모든 화면을 루브릭으로 채점하고 reports/에 회차 리포트를 저장하라"고 위임한다
2. **QA**: qa 에이전트에게 "체크리스트로 케이스·누락 화면을 점검하고 reports/에 회차 리포트를 저장하라"고 위임한다 (1과 동시에 병렬 위임)
3. **판정**: 두 리포트가 저장되면 director 에이전트에게 "최신 리포트를 종합해 통과 선언 또는 수정 지시서를 작성하라"고 위임한다
4. **분기**:
   - 지시서가 "통과 — 루프 정지"면: 사용자에게 최종 결과(총점, 반복 횟수, 남은 P2·P3)를 요약 보고하고 **종료**
   - 지시서에 "사람 개입 필요 항목"이 있으면: 그 항목을 사용자에게 보여주고 **답을 받을 때까지 진행하지 않는다**
   - 수정 지시면: designer 에이전트에게 "reports/의 최신 지시서를 읽고 지시된 항목만 반영하라"고 위임한다
5. **캡처**: screenshot 스킬로 수정된 화면을 다시 찍는다
6. 1로 돌아간다 (회차 +1)

## 정지 조건 (반드시 지킬 것)

- 통과 선언 시 즉시 정지 — 통과했는데 "더 다듬기" 금지
- 3회차 완료 후 미통과면 정지하고, 남은 미통과 항목과 "왜 기계 반복으로 해결이 안 되는지" 추정을 사용자에게 보고한다
- 매 사이클이 끝날 때마다 사용자에게 1줄 경과 보고: `N회차: 총점 NN → NN, P1 누락 N건 → N건`

## 사용자가 범위를 지정한 경우

"02번 화면만 루프 돌려줘"처럼 범위가 지정되면 모든 에이전트 위임에 그 범위를 명시해 전달한다.
