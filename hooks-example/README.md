# 훅 시연 — 파이프라인에 박힌 리뷰

훅(Hook)은 "특정 사건이 일어나면 **무조건** 실행되는 규칙"입니다. 에이전트가 잊어도, 사람이 깜빡해도 실행됩니다. 디자이너 언어로는 **파이프라인에 박힌 리뷰**: 화면 파일이 저장되는 순간 자동으로 걸리는 체크입니다.

기본은 꺼져 있습니다 (실습 흐름이 끊기지 않게). Deliver 세션 말미에 강사가 시연합니다.

## 켜는 법

프로젝트 루트의 `.claude/settings.json`에 아래를 추가하면, **screens/ 안의 HTML이 수정될 때마다** 리마인더가 뜹니다:

```json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Write|Edit",
        "hooks": [
          {
            "type": "command",
            "command": "jq -r '.tool_input.file_path // empty' | grep -q 'screens/.*\\.html' && echo '[훅] 화면이 수정되었습니다. 이 화면은 아직 재채점 전입니다 — 리뷰어 채점을 통과해야 완료입니다.' || true"
          }
        ]
      }
    ]
  }
}
```

## 이게 왜 하네스인가

- 에이전트에게 "수정하면 꼭 재채점해"라고 **말하는 것**은 프롬프트 — 잊힐 수 있습니다
- 수정 이벤트에 리마인더를 **박아 넣는 것**은 하네스 — 잊는 것이 불가능합니다

같은 원리로 실무에서는 저장 시 자동 대비 검사, 커밋 전 루브릭 채점 강제 같은 것을 겁니다. 오늘은 원리만 확인합니다: **검증을 사람의 기억이 아니라 구조에 맡긴다.**
