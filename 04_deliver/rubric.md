# 채점표 (루브릭)

AI 리뷰어가 화면을 채점할 때 쓰는 기준입니다. **1~5번은 채워져 있고, 6~10번은 비어 있습니다.** `/rubric` 으로 빈칸을 채우세요.

- 항목마다 0~10점, 합계 100점
- 통과: 총점 90 이상 + 미달(통과선 미만) 0개 + 치명 위반 없음
- 치명 위반: 명도 대비 미달, 터치 영역 미달, 필수 상태 화면 누락

| # | 항목 | 기준 (화면을 보고 판단할 수 있는 문장) | 확인 방법 | 담당 | 통과선 |
|---|---|---|---|---|---|
| 1 | 디자인 토큰 컬러만 사용 | DESIGN.md 컬러 토큰 표에 없는 색이 화면에 없다. 포인트 컬러는 한 가지다 | measure.md 의 "토큰 밖 컬러" 건수 | 기계 | 7 |
| 2 | 타이포 위계 | 화면에서 가장 큰 글자가 그 화면의 주인공이다. 정보(가격)와 동작(버튼)이 같은 색과 모양이 아니다 | 화면 읽기 | AI | 7 |
| 3 | 컴포넌트 규격 | 버튼 높이, 카드 모서리, 칩 모양이 DESIGN.md 4번 규격과 같다. 규격에 없는 컴포넌트를 만들지 않았다 | 코드와 화면 읽기 | AI | 7 |
| 4 | 명도 대비 | 모든 글자가 배경과 4.5:1 이상(큰 글자 3:1) | measure.md 의 "대비 미달" 건수 | 기계 | 7 |
| 5 | 터치 영역 | 누를 수 있는 모든 요소가 가로세로 44 이상 | measure.md 의 "터치 44 미만" 건수 | 기계 | 7 |
| 6 | (내 판단 기준 1) | 예: 주 버튼 문구가 누르면 일어나는 일을 말한다 | | | 7 |
| 7 | (내 판단 기준 2) | | | | 7 |
| 8 | (가설 검증 1) | 예: 담기를 누른 뒤 결과, 다음 행동, 되돌리기가 한 화면에 보인다 | | | 7 |
| 9 | (가설 검증 2) | | | | 7 |
| 10 | (가장 치명적인 예외 상태) | 예: 빈 장바구니와 담는 사이 품절 화면이 있고, 각각 다음 행동을 제시한다 | 화면 파일 존재 여부 + 내용 | AI | 7 |

## 좋은 항목인지 확인하는 네 가지

1. 화면이나 측정값을 보고 판단할 수 있는가 ("사용성이 좋다"는 안 됨)
2. 한 가지만 묻는가
3. 0점짜리 화면과 10점짜리 화면이 떠오르는가
4. 확인 방법과 담당(기계 / AI / 사람)이 정해져 있는가
