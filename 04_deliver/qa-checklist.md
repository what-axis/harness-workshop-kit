# QA 체크리스트 · 빠지기 쉬운 화면과 상태

QA 에이전트의 점검 범위입니다. 플로우의 **단계마다** 아래 상태를 대입해, 일어날 수 있는데 화면이 없는 것을 찾습니다. 우리 서비스에 맞게 줄을 더하거나 빼세요.

## 1. 상태

| 상태 | 물어볼 질문 |
|---|---|
| 처음(빈 상태) | 데이터가 하나도 없을 때 무엇이 보이는가. 왜 비었는지와 다음 행동이 있는가 |
| 처리 중 | 누른 뒤 결과가 올 때까지 무엇이 보이는가. 두 번 누르면 어떻게 되는가 |
| 성공 | 무엇이 됐는지, 다음에 할 수 있는 일, 되돌리기가 있는가 |
| 오류 | 무슨 일이 있었는지와 지금 할 수 있는 일을 말하는가 |
| 불가 | 품절, 마감, 권한 없음 같은 선택지를 숨기지 않고 대안과 함께 보여 주는가 |
| 부분 | 일부만 성공했을 때(여러 개 중 하나만 품절)는 어떻게 보이는가 |

## 2. 사이에 일어나는 일

- 보는 사이, 담는 사이 **재고나 가격이 바뀐** 경우
- **네트워크가 끊기거나 느린** 경우
- 로그인이 풀리거나 세션이 만료된 경우
- 뒤로 가기, 새로 고침, 앱을 나갔다 돌아온 경우

## 3. 경계값

- 수량 0, 1, 최대 수량
- 아주 긴 상품명, 아주 큰 금액, 옵션이 하나뿐인 상품
- 무료배송 기준을 딱 넘는 순간

## 4. 되돌리기와 막다른 길

- 주요 동작마다 되돌리는 방법이 있는가
- 삭제처럼 되돌릴 수 없는 동작 앞에 확인이 있는가
- 누른 뒤 갈 곳이 없는 버튼, 돌아올 수 없는 화면이 있는가
